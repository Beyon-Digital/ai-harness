# RUN-002 — Implement transactional RunGraph edge mutation and cycle prevention

**Phase:** `runtime`  
**Depends on:** [RUN-001](RUN-001.md), [PST-003](PST-003.md)

## Goal

Implement dependency graph storage with serial cycle validation while deriving parent/child ancestry from the single canonical `runs.parent_run_id` field.

## Required outputs / expected code locations

- `crates/run-graph/src/graph.rs`
- `crates/run-graph/src/repository.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Treat `runs.parent_run_id` as the only persisted parent-child relationship; do not duplicate parent-child rows.
2. Validate source/target same Task graph.
3. Limit dependency target to Created/unclaimed Ready.
4. Inside write transaction perform reachability/cycle check then insert edge and increment graph revision.
5. Use unique edge constraint to make duplicate insert idempotent/conflict-safe.
6. Emit graph events through coordinator/outbox integration.
