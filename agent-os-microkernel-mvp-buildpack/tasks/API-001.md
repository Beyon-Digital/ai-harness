# API-001 — Implement local gRPC server over Unix-domain socket

**Phase:** `api`  
**Depends on:** [PST-004](PST-004.md), [FND-006](FND-006.md), [FND-002](FND-002.md)

## Goal

Expose the base control plane locally without bypassing internal command semantics.

## Required outputs / expected code locations

- `crates/control-api/src/server.rs`
- `crates/control-api/src/uds.rs`
- `crates/agentd/src/api.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Create UDS in application runtime directory with restrictive permissions.
2. Remove stale socket only after verifying no active daemon lock owner.
3. Serve tonic gRPC over UDS.
4. Add graceful stop tied to daemon draining.
5. Read Unix peer credentials and map the peer UID to the configured local principal; reject mismatched principal claims.
6. Create local bootstrap actor context abstraction rather than hard-code unauthenticated global authority in handlers.

## Required tests

- `socket permission test`
- `second daemon cannot steal socket`
- `graceful shutdown test`
- `client connection smoke test`
- `peer principal mismatch rejected`
