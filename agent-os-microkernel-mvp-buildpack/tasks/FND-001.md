# FND-001 — Bootstrap Rust workspace and quality gates

**Phase:** `foundation`  
**Depends on:** None

## Goal

Create the compilable Rust workspace, toolchain policy, shared dependency policy, CI commands, and empty crate boundaries without implementing runtime behavior.

## Required outputs / expected code locations

- `Cargo.toml`
- `rust-toolchain.toml`
- `.cargo/config.toml`
- `crates/*/Cargo.toml`
- `.github/workflows/ci.yml`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Create all crates listed in `architecture/crate-map.md` with minimal `lib.rs`/`main.rs`.
2. Use workspace dependency declarations for Tokio, tracing, serde, prost/tonic, uuid, sha2, sqlx/rusqlite choice, thiserror, async-trait, tempfile, proptest. Pin normal semver ranges; do not vendor code.
3. Set edition and MSRV/toolchain explicitly.
4. CI must run format, clippy with warnings denied, workspace tests, and build all targets.
5. `agentd` binary should start and exit cleanly with a placeholder composition root; no DB/API yet.

## Required tests

- `cargo check --workspace`
- `cargo fmt --check`
- `cargo clippy --workspace --all-targets -- -D warnings`
- `cargo test --workspace`

## Acceptance criteria

- [ ] All crates compile on macOS target.
- [ ] No crate cycles.
- [ ] CI configuration expresses the same quality gates documented in AGENTS.md.

## Forbidden shortcuts

- Do not implement internal crates as network services.
- Do not place domain types in `agentd`.

## Completion evidence

Record in `TASK_STATUS.yaml`:

- exact test commands executed;
- pass/fail result;
- notable concurrency/fault-injection seed if relevant;
- git commit SHA if available;
- any non-blocking follow-up explicitly outside this task.
