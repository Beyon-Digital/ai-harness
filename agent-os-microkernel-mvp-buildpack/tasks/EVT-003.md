# EVT-003 — Implement outbox dispatcher with journal-first publication

**Phase:** `events`  
**Depends on:** [EVT-002](EVT-002.md), [PST-005](PST-005.md), [FND-005](FND-005.md)

## Goal

Project committed outbox events safely to Event Journal, surviving duplicate work and crashes.

## Required outputs / expected code locations

- `crates/events/src/dispatcher.rs`
- `crates/agentd/src/workers/outbox.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Poll unpublished outbox rows ordered per stream.
2. Append to Event Journal.
3. Only after journal success mark journal publication in KernelStore.
4. Then hand event to Live Bus hook.
5. Add bounded retry/backoff for transient journal errors without blocking command commits.
6. Inject fault after journal append before publication mark.

## Required tests

- `crash/restart exact reappend test`
- `journal unavailable => outbox backlog grows, commands still commit`
- `per-stream order test`
