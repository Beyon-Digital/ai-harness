# ADP-001 — Implement supervised external process lifecycle and private socketpair IPC

**Phase:** `adapters`  
**Depends on:** [PST-004](PST-004.md), [FND-006](FND-006.md)

## Goal

Create the secure process-launch substrate for external loops/adapters.

## Required outputs / expected code locations

- `crates/process-supervisor/src/lib.rs`
- `crates/process-supervisor/src/spawn.rs`
- `crates/process-supervisor/src/child.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Create Unix socketpair before spawn.
2. Map child end to fixed inherited FD and close unrelated descriptors where practical.
3. Keep stdout/stderr separate.
4. Track PID/start identity/adapter instance ID/bundle digest.
5. Implement graceful shutdown then kill escalation.
6. Associate process with daemon fencing epoch and invalidate on daemon drain.

## Required tests

- `private IPC works`
- `unrelated local process cannot race a listener because none exists`
- `child crash captured`
- `descendant cleanup fixture`
