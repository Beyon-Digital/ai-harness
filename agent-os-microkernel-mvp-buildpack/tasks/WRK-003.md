# WRK-003 — Implement Workspace Coordinator leases, transfer, fork, and merge

**Phase:** `workspace`  
**Depends on:** [WRK-002](WRK-002.md), [RUN-004](RUN-004.md), [SEC-002](SEC-002.md)

## Goal

Coordinate write authority so subagents can receive useful parent scope without unsafe concurrent mutation.

## Required outputs / expected code locations

- `crates/workspace/src/coordinator.rs`
- `crates/kernel-store-sqlite/src/repos/workspace_leases.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Acquire READ_ONLY/EXCLUSIVE_WRITE leases with epoch.
2. Transfer exclusive lease parent->child using expected epoch and delegated capability.
3. For T0 coordinator-mediated writes, old lease token fails immediately after transfer. Clearly mark that raw host file descriptors are not enforceable security isolation.
4. Default parallel write children to isolated forks.
5. Implement explicit merge/apply operation for Git worktrees; surface conflicts rather than auto-resolving silently.
6. Reject SHARED_COORDINATED_WRITE unless adapter advertises locking/version/conflict capabilities.

## Required tests

- `exclusive transfer stale token rejected`
- `two active exclusive leases impossible`
- `parallel forks independent`
- `merge success and conflict tests`
- `shared mode rejected by local adapter`

## Acceptance criteria

- [ ] Parent can delegate useful exclusive/forked scope while authority never amplifies.
