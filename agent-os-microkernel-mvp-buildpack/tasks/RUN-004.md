# RUN-004 — Implement cancellation epochs and subtree cancellation

**Phase:** `runtime`  
**Depends on:** [RUN-002](RUN-002.md), [RUN-001](RUN-001.md)

## Goal

Prevent child-spawn escape races and provide deterministic cancellation propagation.

## Required outputs / expected code locations

- `crates/run-graph/src/cancellation.rs`
- `crates/runtime/src/cancel.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Cancellation command increments parent cancellation_epoch inside transaction.
2. Traverse known descendants and transition eligible runs toward Cancelling/Cancelled according to state.
3. Child creation must provide observed parent cancellation epoch and compare at commit.
4. A child created after epoch advance is rejected or born cancelled according to explicit command policy; MVP default reject spawn.

- `nested descendant propagation test`
- `terminal child unchanged test`

## Acceptance criteria
