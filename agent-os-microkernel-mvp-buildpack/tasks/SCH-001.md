# SCH-001 — Implement durable one-shot scheduler timers

**Phase:** `scheduler`  
**Depends on:** [CMD-001](CMD-001.md), [PST-003](PST-003.md), [FND-005](FND-005.md)

## Goal

Provide crash-safe timers with linearized fire/cancel semantics.

## Required outputs / expected code locations

- `crates/scheduler/src/lib.rs`
- `crates/kernel-store-sqlite/src/repos/timers.rs`
- `crates/agentd/src/workers/scheduler.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Schedule via Command Coordinator.
2. Worker claims due timer using CAS Scheduled->Claimed and version/fence.
3. Cancel CASes Scheduled->Cancelled.
4. Claimed timer invokes a normal internal kernel command then commits Fired if current.
5. Use ManualClock in tests.

## Required tests

- `fire/cancel race exactly one winner`
- `restart after claim recovers safely`
- `double-fire prevention`

## Acceptance criteria

- [ ] Timer worker never mutates run state directly.
