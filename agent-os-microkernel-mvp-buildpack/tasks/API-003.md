# API-003 — Implement Event API read and live subscription

**Phase:** `api`  
**Depends on:** [API-001](API-001.md), [EVT-004](EVT-004.md), [EVT-002](EVT-002.md)

## Goal

Expose durable history and journal-backed resumable live subscriptions.

## Required outputs / expected code locations

- `crates/control-api/src/event_service.rs`
- `proto/events/**`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. ReadStream directly from Event Journal with authorization/filtering hook.
2. Subscribe starts by replaying journal after requested cursor then attaches live bus without a gap; use a handoff strategy that accounts for events published during replay.
3. On live lag, terminate with resume cursor.
4. Apply sensitivity projection policy; MVP local owner can request Private but Secret payload fields remain protected by event design.

- `subscriber lag/resume test`
- `journal unavailable behavior`
