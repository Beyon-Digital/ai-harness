# FND-005 — Build deterministic testkit and fault-injection hooks

**Phase:** `foundation`  
**Depends on:** [FND-001](FND-001.md), [FND-003](FND-003.md)

## Goal

Provide reusable clocks, ID factories, temporary directories, barrier/race helpers, and named fault points needed to prove crash/concurrency semantics.

## Required outputs / expected code locations

- `crates/testkit/src/clock.rs`
- `crates/testkit/src/ids.rs`
- `crates/testkit/src/faults.rs`
- `crates/testkit/src/process.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Define `Clock` trait with SystemClock and ManualClock.
2. Define test-only deterministic ID source where tests need repeatability; production uses UUIDv7.
3. Define named `FaultPoint` interface that can fail/panic/abort in integration harness at persistence boundaries.
4. Provide helpers for spawning/terminating `agentd` against temp application dirs.
5. Fault hooks must compile out or be disabled by default in production.

- `manual clock tests`
- `fault-point trigger-once tests`
- `temp daemon harness smoke test`
