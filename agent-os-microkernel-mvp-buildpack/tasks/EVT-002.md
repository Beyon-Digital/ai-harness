## Implementation steps

1. Create separate SQLite DB/file from kernel.db.
2. Append requires expected head/contiguous events.
3. Same event ID at same sequence => idempotent success.
4. Same sequence/different event => conflict.
5. Read stream supports from_sequence/limit and retention-gap field (always false in inception implementation unless deliberate test fixture).
