# RUN-005 — Implement startup run reconstruction and recovery dispositions

**Phase:** `runtime`  
**Depends on:** [RUN-003](RUN-003.md), [RUN-004](RUN-004.md), [PST-004](PST-004.md)

## Goal

Reconstruct non-terminal runs after daemon restart and persist whether they may safely resume.

## Required outputs / expected code locations

- `crates/runtime/src/recovery.rs`
- `crates/agentd/src/recovery.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Load non-terminal runs and frozen environments.
2. Classify pending effects/resources/timers/process associations.
3. Set `NeedsReconciliation`, `BlockedUnknownEffect`, `BlockedMissingResource`, or `Recovering` without abusing RunState.
4. Do not issue loop turns until run recovery is Normal and any claim is valid/reacquired.

## Required tests

- `restart with Running run/no effect`
- `restart with unknown effect`
- `restart with missing adapter binding`
- `recovery disposition persistence tests`

## Acceptance criteria

- [ ] Daemon never blindly resumes a run whose external effect outcome is ambiguous.
