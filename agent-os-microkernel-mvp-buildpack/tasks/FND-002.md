**Phase:** `foundation`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Copy `/contracts` preserving paths.
2. Configure `prost-build`/`tonic-build` to generate code from the snapshot.
3. Ensure generated code is reproducible and either checked in with freshness check or generated in build; choose one policy and document it.
4. Add contract hash verification against `contracts/contract-lock.sha256`.
5. Correct inception schema/manifest constants to 1 as recorded in SOURCE_CORRECTIONS.md.

## Required tests

- `cargo test -p domain contract_codegen`
- `script verifies contract lock hashes`
- `schema JSON parses and const version == 1`

## Acceptance criteria

- [ ] Generated protobuf types compile.
- [ ] Changing a contract without updating the lock fails validation.
- [ ] No second hand-written copy of protobuf message structs is created.

## Forbidden shortcuts

- Do not edit generated code manually.
