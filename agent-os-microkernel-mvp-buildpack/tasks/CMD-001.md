# CMD-001 — Implement Command Coordinator linearization path

**Phase:** `control-core`  
**Depends on:** [PST-005](PST-005.md), [FND-006](FND-006.md)

## Goal

Create the sole state-changing command path and prove commit/replay semantics before higher-level commands are added.

## Required outputs / expected code locations

- `crates/command-coordinator/src/lib.rs`
- `crates/command-coordinator/src/envelope.rs`
- `crates/command-coordinator/src/handler.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Implement generic typed command dispatch table/internal enum.
2. Validate digest, deadline, principal/actor context.
3. Begin fenced transaction; perform idempotency lookup; invoke command handler with transaction; insert outbox/idempotency; commit; return committed outcome.
4. Add fault points before commit, after commit before response.
5. Queries must not use command path; all mutations must.

## Required tests

- `fault before commit => no mutation`
- `fault after commit => replay returns stored outcome`
- `idempotency conflict test`
- `fence mismatch test`

## Acceptance criteria

- [ ] No state-changing handler can obtain a raw store connection outside coordinator.
