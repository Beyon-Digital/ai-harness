# ADP-002 — Implement framed protobuf external adapter protocol

**Phase:** `adapters`  
**Depends on:** [ADP-001](ADP-001.md), [FND-002](FND-002.md)

## Goal

Implement bootstrap/hello identity validation and request/response/cancel/health framing.

## Required outputs / expected code locations

- `crates/adapter-protocol/src/lib.rs`
- `crates/adapter-protocol/src/framing.rs`
- `crates/adapter-protocol/src/handshake.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Use length-delimited protobuf frames with maximum frame size.
2. Kernel sends bootstrap first; child must echo matching instance/protocol/digest identity in Hello.
3. Add request ID, response ID, deadline, cancel, ping/pong and graceful-shutdown frames around canonical payload messages.
4. Reject malformed/oversized/unexpected-order frames.

## Required tests

- `wrong digest handshake fails`
- `wrong instance/nonce/protocol fails`
- `oversized frame rejected`
- `cancel frame delivered`
- `deadline closes request`

## Acceptance criteria
