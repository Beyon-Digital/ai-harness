# PST-001 — Create inception SQLite KernelStore schema

**Phase:** `persistence`  
**Depends on:** [FND-003](FND-003.md), [FND-004](FND-004.md)

## Goal

Create `kernel.db` bootstrap schema exactly once from the inception SQL and assert structural invariants at startup.

## Required outputs / expected code locations

- `schema/kernel_store.sql`
- `crates/kernel-store-sqlite/src/schema.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Use `specs/kernel-store-schema.sql` as baseline.
2. Create DB in application data directory with restrictive filesystem permissions.
3. Apply PRAGMAs foreign_keys, WAL, synchronous FULL, busy_timeout.
4. Record inception schema version 1 in `kernel_meta`.
5. On startup reject any schema other than the exact inception schema version.
6. Add repository integration test that inspects required tables/indexes/constraints.

## Required tests

- `fresh DB bootstrap test`
- `reopen same version test`
- `wrong schema version fails closed`
- `foreign-key/unique constraint tests`

## Acceptance criteria

- [ ] Only the exact inception schema is accepted.
