# CFG-002 — Implement immutable config generations and tested activation

**Phase:** `config`  
**Depends on:** [CFG-001](CFG-001.md), [CMD-001](CMD-001.md)

## Goal

Persist proposed generations and activate only validated/tested immutable documents.

## Required outputs / expected code locations

- `crates/config-engine/src/generations.rs`
- `crates/config-engine/src/activate.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Hash exact generation document.
2. Propose via command coordinator.
3. Run schema/adapter/capability validation and smoke checks without changing active pointer.
4. Mark test result.
5. Compare generation-global service bindings against the currently running daemon bindings; if any differ, reject live activation with `DAEMON_RESTART_REQUIRED`.
6. Activate eligible generation using CAS on active generation revision.
7. Implement reactivation of previous known-good generation for failed activation safety.

## Required tests

- `untested generation cannot activate`
- `CAS race one winner`
- `generation-global service change returns DAEMON_RESTART_REQUIRED and does not move pointer`
- `failed smoke leaves pointer unchanged`
- `reactivation test`

## Acceptance criteria

- [ ] Existing run records are never rewritten on activation.
