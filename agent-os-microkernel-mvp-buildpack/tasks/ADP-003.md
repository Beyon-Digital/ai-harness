# ADP-003 — Implement content-addressed adapter registry

**Phase:** `adapters`  
**Depends on:** [ADP-002](ADP-002.md), [PST-003](PST-003.md)

## Goal

Register immutable adapter identities and persist trust/conformance metadata.

## Required outputs / expected code locations

- `crates/adapter-registry/src/registry.rs`
- `crates/adapter-registry/src/manifest.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Parse inception extension manifest version 1.
2. Compute bundle digest in kernel from manifest + executable/package bytes + dependency lock inventory for fixture bundles.
3. Persist `(id,version,digest)` identity and manifest digest.
4. Do not execute mutable path until digest has been verified immediately before spawn.
5. Represent trust/conformance/enabled state.

## Required tests

- `mutating bundle changes digest`
- `same name/version different digest treated as different identity`
- `spawn-time digest mismatch rejected`
