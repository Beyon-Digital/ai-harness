# WRK-002 — Implement local workspace adapter and Git worktree primitives

**Phase:** `workspace`  
**Depends on:** [WRK-001](WRK-001.md), [ADP-004](ADP-004.md)

## Goal

Create local mutable workspaces with reproducible base revision and isolated fork capability.

## Required outputs / expected code locations

- `crates/workspace/src/local.rs`
- `crates/workspace/src/git.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Create/open application-authorized local workspace.
2. For Git repo record exact HEAD/base revision.
3. Fork child using Git worktree/branchless detached worktree or explicit implementation documented by adapter.
4. For non-Git fixture support copied directory fork with weaker capability metadata.
5. All file operations go through normalized relative paths.

## Required tests

- `create/read/write/list`
- `Git fork starts at parent base revision`
- `non-Git fork capability label`
- `path traversal denied`

## Acceptance criteria

- [ ] Adapter reports actual capabilities; it does not pretend copy fork is Git-semantic.
