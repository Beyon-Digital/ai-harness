# EFF-004 — Implement effect reconciliation and Unknown handling

**Phase:** `effects`  
**Depends on:** [EFF-003](EFF-003.md), [RUN-005](RUN-005.md)

## Goal

Recover safely when dispatch outcome is ambiguous.

## Required outputs / expected code locations

- `crates/effects/src/reconcile.rs`
- `crates/runtime/src/effect_recovery.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Define adapter executor interface `execute/status/reconcile/cancel` with stable operation ID.
2. On recovery inspect effective contract.
3. Use status/result lookup when supported.
4. Redispatch same operation ID only when idempotency evidence and policy allow.
5. Otherwise mark Unknown and set owning run `BlockedUnknownEffect`.
6. Implement explicit admin/user command `ResolveUnknownEffect` supporting mark_succeeded, mark_failed, or retry_accepting_duplicate_risk with approval/capability check.
