# SEC-001 — Implement principals, actors, delegation chains, and grant lineage

**Phase:** `security`  
**Depends on:** [FND-003](FND-003.md), [PST-003](PST-003.md)

## Goal

Create persisted authority lineage used by every privileged call.

## Required outputs / expected code locations

- `crates/identity/src/lib.rs`
- `crates/identity/src/delegation.rs`
- `crates/kernel-store-sqlite/src/repos/security.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Represent principal, actor, run context and ordered delegation hops.
2. Persist capability grant IDs at each hop.
3. Provide `derive_child_chain` that can only reference a subset of parent grants.
4. Validate chain integrity on load.

## Required tests

- `subset delegation tests`
- `tampered/missing parent grant tests`
- `serialization/persistence tests`

## Acceptance criteria

- [ ] A child cannot construct an authority chain containing capabilities absent from ancestors.
