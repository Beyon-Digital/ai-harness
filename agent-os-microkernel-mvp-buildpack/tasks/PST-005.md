# PST-005 — Implement idempotency and transactional outbox primitives

**Phase:** `persistence`  
**Depends on:** [PST-003](PST-003.md), [PST-004](PST-004.md)

## Goal

Provide repository primitives used by every mutating command for replay safety and durable event projection.

## Required outputs / expected code locations

- `crates/kernel-store-sqlite/src/repos/idempotency.rs`
- `crates/kernel-store-sqlite/src/repos/outbox.rs`
- `crates/events/src/outbox.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Lookup idempotency by `(principal_id,idempotency_key)`.
2. Reject same key with different request digest.
3. Store exact outcome code/payload in command transaction.
4. Allocate contiguous stream sequence from event_stream_heads.
5. Insert immutable outbox rows with unique event ID and stream sequence.
6. Expose ordered unpublished scan without changing canonical event content.

## Required tests

- `same key/same digest replay test`
- `same key/different digest conflict`
- `concurrent sequence allocation test`
- `outbox duplicate event conflict test`

## Acceptance criteria
