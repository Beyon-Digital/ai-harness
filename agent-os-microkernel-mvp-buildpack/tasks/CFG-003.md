# CFG-003 — Implement runtime profile resolution and frozen ResolvedRunEnvironment

**Phase:** `config`  
**Depends on:** [CFG-002](CFG-002.md), [WRK-003](WRK-003.md), [SBOX-001](SBOX-001.md), [ART-001](ART-001.md)

## Goal

Resolve exact run-scoped dependencies once and persist them immutably before a run executes.

## Required outputs / expected code locations

- `crates/config-engine/src/profile.rs`
- `crates/runtime/src/resolved_environment.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Resolve profile inheritance/overrides.
2. Resolve each requested port to exact adapter ID/version/digest/capabilities.
3. Record AgentSpec/loop digest, config generation, workspace base/access/lease, kernel/protocol versions, grants/approvals.
4. Persist environment and bindings atomically with run start/binding transition.
5. Reject any attempt to update environment after creation.

## Required tests

- `Run A under G1, activate G2, A still returns G1 bindings`
- `DB update attempt rejected by repository API/constraint policy`
- `missing required adapter fails run start before execution`

## Acceptance criteria

- [ ] Historical audit needs no mutable current registry/config to know original bindings.
