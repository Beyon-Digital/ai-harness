# RUN-000 — Implement AgentSpec, Session, Task, and initial AgentRun commands

**Phase:** `runtime`  
**Depends on:** [CMD-001](CMD-001.md), [PST-003](PST-003.md)

## Goal

Implement immutable AgentSpec revisions plus Session/Task/Created-Run creation commands so later runtime/graph logic has complete canonical roots.

## Required outputs / expected code locations

- `crates/runtime/src/agent_spec.rs`
- `crates/runtime/src/session.rs`
- `crates/runtime/src/task.rs`
- `crates/runtime/src/create_run.rs`
- `crates/kernel-store-sqlite/src/repos/agent_specs.rs`
- `crates/kernel-store-sqlite/src/repos/tasks.rs`

## Normative inputs

- `specs/agent-task-session.md`
- `specs/command-coordinator.md`
- `DECISIONS.md`

## Implementation steps

1. Implement AgentSpec `(id, version, digest, immutable body)` repository and validation.
2. Implement Session creation bound to principal.
3. Implement immutable Task creation.
4. Implement `CreateTaskRun` command that creates a `Created` run and parent linkage through `parent_run_id` when applicable.
5. For child creation, update graph revision and validate observed parent cancellation epoch once RUN-004 supplies that logic; expose a narrow hook rather than duplicating cancellation policy.
6. Do not transition the run to `Ready` until CFG-003 persists the complete ResolvedRunEnvironment.
7. Emit canonical outbox events and store idempotency outcome in the same command transaction.

## Required tests

- `immutable AgentSpec revision tests`
- `session/task idempotent creation tests`
- `child run parent linkage test`
- `run starts Created without silently becoming Ready`

## Acceptance criteria

- [ ] Existing AgentSpec revision bytes/digest can never be overwritten.
- [ ] CreateTaskRun atomically creates required task/run/parent metadata/outbox/idempotency records.
- [ ] A run cannot become Ready without a persisted ResolvedRunEnvironment.

## Forbidden shortcuts

- Do not mutate old AgentSpec versions in place.
- Do not derive historical agent version from current configuration.
- Do not duplicate parent-child relationship into a second edge table.
