# ART-001 — Implement local ArtifactStore and metadata

**Phase:** `artifacts`  
**Depends on:** [WRK-001](WRK-001.md), [PST-003](PST-003.md)

## Goal

Persist durable outputs by logical artifact URI with digest/classification metadata.

## Required outputs / expected code locations

- `crates/artifacts/src/lib.rs`
- `crates/artifacts/src/local.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Write artifact content atomically to app-owned directory.
2. Compute content SHA-256 and metadata.
3. Store/lookup metadata by artifact ID; associate run/effect.
4. Support range read/head/list.
5. Use sensitivity/retention classification.

## Required tests

- `put/get digest test`
- `atomic write failure leaves no partial visible artifact`
- `logical URI no physical path leak`
