**Phase:** `security`  
**Depends on:** [SEC-001](SEC-001.md), [FND-004](FND-004.md)

## Implementation steps

1. Implement capability families from contract catalog.
2. Represent scoped targets (workspace URI/path, network domains, secret URI, child count, config operation).
3. Evaluate system policy + principal grants + delegation chain + actor/extension restrictions.
4. Return Allow/Deny/RequireApproval.
5. Add joint-risk rule for secret use plus broad egress.
