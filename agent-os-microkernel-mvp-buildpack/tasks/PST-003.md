# PST-003 — Implement SQLite KernelStore transactions and repositories

**Phase:** `persistence`  
**Depends on:** [PST-001](PST-001.md), [PST-002](PST-002.md), [FND-005](FND-005.md)

## Goal

Implement all base repository operations and transaction semantics in SQLite.

## Required outputs / expected code locations

- `crates/kernel-store-sqlite/src/lib.rs`
- `crates/kernel-store-sqlite/src/txn.rs`
- `crates/kernel-store-sqlite/src/repos/*.rs`

## Normative inputs

- Use the component specs linked from the goal/steps and `DECISIONS.md`.

## Implementation steps

1. Use explicit write transactions and `BEGIN IMMEDIATE` for graph/head/claim mutations that must reserve writer ordering before validation.
2. Implement typed row encoding/decoding with enum validation.
3. Implement CAS helpers for run revision, effect state/fence, timer version, config pointer, workspace lease epoch.
4. Implement event stream head increment and outbox insert in the same transaction.
5. Map constraint/busy errors into stable error codes.

## Required tests

- `transaction rollback test`
- `CAS conflict tests`
- `concurrent writer contention test`
- `outbox/stream sequence uniqueness tests`
